# 📚 本地文档检索助手（RAG 前端工具）

基于 TF‑IDF 与余弦相似度的轻量级中文文档检索系统。  
从指定文件夹读取 `.txt` 文件，自动分词并建立索引；用户输入问题后，系统召回最相关的段落，并生成可直接复制到任意大模型（如 DeepSeek、通义千问、ChatGPT）的 Prompt，帮助您快速获得基于本地资料的精准回答。

---

## ✨ 功能特点

- 📂 **批量加载**：读取 `./data` 目录下所有 `.txt` 文件，按空行切分为独立段落。
- 🧠 **中文分词**：集成 `jieba` 分词，支持自定义停用词过滤。
- 📊 **向量检索**：基于 TF‑IDF 和余弦相似度，快速返回与问题最相关的 `top_k` 个段落。
- 🤖 **即用 Prompt**：自动拼接召回段落与用户问题，生成结构化提示词，方便复制到大模型获取答案。
- 💻 **交互式命令行**：运行后持续接收用户输入，支持 `exit` 退出。

⚠️ 注意事项
本程序 不包含大模型，仅生成 Prompt，需自行复制到外部模型使用。

检索效果受文档质量和分词准确性影响，建议文档内容清晰、段落划分合理。

若 data 文件夹为空或无 .txt 文件，程序会提示并退出。

🔧 可能的问题与改进方向
内存占用：当文档数量极大（数万段落）时，TF‑IDF 矩阵可能占用较多内存，可考虑分批处理。

语义理解有限：TF‑IDF 基于词频，无法识别同义词。如需更精准检索，可升级为 Sentence‑BERT 等向量嵌入模型。

自动调用大模型 API：当前为手动复制，您可扩展代码直接调用 API（需添加 API Key）。
